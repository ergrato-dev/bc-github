# Webgrafía — Semana 01

Documentación y artículos. La oficial primero: es la única que no envejece mal.

## Documentación oficial

| Recurso | Por qué vale la pena |
|---------|----------------------|
| [Git — Reference](https://git-scm.com/docs) | La referencia completa de cada comando. `git help <comando>` te da lo mismo sin salir de la terminal |
| [`git rebase`](https://git-scm.com/docs/git-rebase) | La sección "Interactive Mode" explica cada verbo con ejemplos |
| [`git bisect`](https://git-scm.com/docs/git-bisect) | Los ejemplos de `bisect run` con scripts son lo mejor del documento |
| [`git worktree`](https://git-scm.com/docs/git-worktree) | Corta y suficiente para no volver a usar `stash` por costumbre |
| [GitHub Docs — Verificación de firmas](https://docs.github.com/authentication/managing-commit-signature-verification/about-commit-signature-verification) | Explica cuándo un commit sale `Verified`, `Partially verified` o nada |
| [GitHub Docs — Firmar con SSH](https://docs.github.com/authentication/managing-commit-signature-verification/signing-commits) | El flujo con `gpg.format ssh`, que es el que usamos |
| [GitHub Docs — Tipos de autenticación](https://docs.github.com/authentication/keeping-your-account-and-data-secure/about-authentication-to-github) | El mapa de credenciales: PAT clásico, fine-grained, App, `GITHUB_TOKEN` |
| [Manual de `gh`](https://cli.github.com/manual/) | Todos los subcomandos con sus flags. Búscalo antes de improvisar un `curl` |
| [GitHub REST API](https://docs.github.com/rest) | Referencia de endpoints. La usarás en cada `checks.json` |

## Artículos

| Recurso | Por qué vale la pena |
|---------|----------------------|
| [Think Like (a) Git](https://think-like-a-git.net/) | La mejor explicación del modelo de grafo y de por qué "no se pierde nada" |
| [Oh Shit, Git!?!](https://ohshitgit.com/es/) | Recetario de desastres frecuentes y su rescate. Guárdalo en marcadores |
| [A Note About Git Commit Messages (Tim Pope)](https://tbaggery.com/2008/04/19/a-note-about-git-commit-messages.html) | El origen del "título en imperativo, 50 caracteres, cuerpo a 72" |
| [Git from the inside out](https://maryrosecook.com/blog/post/git-from-the-inside-out) | Recorre qué escribe Git en disco en cada comando |
| [How to Write a Git Commit Message (Chris Beams)](https://cbea.ms/git-commit/) | Las siete reglas, con ejemplos de por qué importan |
