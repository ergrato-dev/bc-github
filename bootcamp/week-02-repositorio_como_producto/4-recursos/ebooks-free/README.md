## Qué leer si solo tienes una hora

**Open Source Guides — "Starting an Open Source Project"**. Cubre licencias,
README, CONTRIBUTING y código de conducta en una sola lectura, y está escrito por
el mismo equipo que diseñó el *community profile* que vas a poner al 100%.
