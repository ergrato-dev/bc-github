# 🤝 Código de Conducta

## Nuestro compromiso

Este bootcamp existe para enseñar GitHub como plataforma de ingeniería de forma
rigurosa y accesible. Esperamos de cualquier persona que participe (estudiantes,
instructores, colaboradores externos) un trato respetuoso, sin importar nivel de
experiencia, origen, género, orientación, discapacidad o cualquier otra
característica personal.

## Se espera

- Dar y recibir retroalimentación técnica de forma constructiva. Este bootcamp
  entrena code review: la crítica va al código, nunca a la persona.
- Respetar el ritmo de aprendizaje de otros — todos empezaron en algún punto.
- Reportar bugs, erratas o contenido desactualizado del bootcamp de forma
  concreta y verificable (archivo, semana, línea si aplica).
- Reconocer que el contenido de este repo está generado con asistencia de IA
  (Claude/Copilot) y revisado por el autor — el estándar de calidad es el mismo
  independientemente de la herramienta usada para producirlo.

## No se tolera

- Acoso, insultos o comentarios despectivos hacia cualquier persona.
- Compartir públicamente datos personales de otros (doxxing) sin consentimiento.
- Publicar credenciales, tokens o secretos de terceros en issues, PRs o
  discusiones — ni siquiera "de ejemplo". Si encuentras un secreto expuesto,
  repórtalo en privado (ver [SECURITY.md](SECURITY.md)).
- Abrir PRs o issues de relleno contra proyectos open source ajenos para inflar
  un perfil. La Semana 19 pide una contribución **real y útil**; el spam a
  mantenedores es una falta grave y perjudica a toda la comunidad.
- Spam o autopromoción no solicitada en issues/PRs de este repositorio.

## Aplicación

Los incidentes se reportan a **elparcheti@gmail.com**. Todo reporte se revisa
caso por caso; las respuestas van desde una advertencia privada hasta la
remoción de acceso al repositorio o al programa, según la gravedad.

## Alcance

Aplica a cualquier espacio asociado al bootcamp: este repositorio (issues, PRs,
discussions, commits), los repositorios de proyecto de los estudiantes y
cualquier canal de comunicación oficial del programa donde se discuta su
contenido.
